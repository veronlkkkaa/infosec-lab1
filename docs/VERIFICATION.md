## Что именно проверено

JUnit использует настоящий Spring-контекст, SecurityFilterChain, Nimbus JWT, BCrypt и H2 in-memory.
Проверены: вход, неправильный пароль, SQLi, обязательные claims/время/подпись JWT, доступ к своим
заметкам, XSS, owner_id, неизвестные/неправильные поля, 16 КиБ, 72 UTF-8 байта для BCrypt,
лимит входа, чрезмерный Authorization, заголовки безопасности и удалённый пользователь.

HTTP дополнительно проверяет запуск Boot JAR, bootstrap двух временных аккаунтов, ответы
200/201/400/401/413, XSS, SQLi, изоляцию владельцев, изменённую подпись JWT и файловую H2
после перезапуска. Это 15 сценариев, а не полный DAST-аудит. Временные ключи и пароли
генерировались самой проверкой, не извлекались из личных хранилищ и не входят в отчёт.

## Исправления

1. Числа и boolean в строковых JSON-полях отклоняются явно через coercion config; сохранён
   регрессионный тест. При миграции на Jackson 3 настройка перенесена на JsonMapperBuilderCustomizer.
2. Spring BOM подключён через Gradle platform к приложению: он не понижает зависимости
   отдельного инструмента SpotBugs (ранее commons-lang3 вызывал NoClassDefFoundError).
3. JSON-ошибки сериализуются вместо ручной конкатенации; исключение XSS_SERVLET не добавлялось.
4. SAST-исключения ограничены классом/методом/типом: stateless CSRF, известные эндпоинты,
   чтение длины Authorization. ignoreFailures=false сохранён.
5. Исправлен пустой SCA-отчёт: родительская testAndDevelopmentOnly ошибочно приводила к
   пропуску runtimeClasspath. Ограничен явный runtimeClasspath, skipTestGroups=false;
   контроль SHA-256 теперь отклоняет неполный охват. Анализ выполняется при каждом вызове задачи.
6. Полный SCA старых версий: 252 сопоставления, 46 уникальных CVE. Это не доказательство
   достижимости каждой проблемы в приложении. Обновлены Kotlin 2.2.21 → 2.4.21,
   Spring Boot 3.5.16 → 4.1.2, Spring Framework/Security/Tomcat и Jackson через BOM.
   Адаптированы Jackson 3, новые starter-модули, пакет AutoConfigureMockMvc и nullable API.
   Новых исключений CVE нет; повторный SCA чистый, тесты и HTTP-сценарии повторены.
